Storage Doctor V.20261122.01

Shows what is filling your storage (AI agent files, photos, big files, duplicates, files generated in a loop) and helps you keep it at 50 % used.

MacBook

Runs on your Mac and opens in your browser. Nothing is uploaded.

  1. Open Terminal (press ⌘ Space, type “Terminal”).
  2. Paste this and press Return:
    curl -fsSL https://github.com/natadej/mac-storage-doctor/releases/latest/download/install.sh | bash
  3. The dashboard opens in your browser. Leave the Terminal window open while you use it.
  4. For a complete scan: System Settings → Privacy & Security → Full Disk Access → turn on Terminal, then run the command again.

Next time, double-click start.command in ~/Applications/Mac Storage Doctor. Running the command again updates to the newest version.

Or download the .zip

Android

Scans the phone's own storage. Android 8 or newer.

Download APK
  1. Open this page on your phone and tap Download APK.
  2. Open the downloaded file. If asked, allow your browser to install unknown apps.
  3. In the app, tap Allow all files access, and Allow usage access to see how much each app uses.

It isn't on Google Play, because Play only allows “All files access” for certain kinds of apps.

Why not just a website? A web page can't read your Mac's or phone's disk or move files to the Trash, so the app has to run on the device itself. All versions: releases · Source: GitHub
